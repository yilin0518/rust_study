# Week 1 文档说明

本目录将每天的文档分成两类：

- `lesson_plans/`：教学教案。它规定当天的学习顺序、观察点、提问顺序和完成标准，供教学过程使用。
- `study_materials/`：学习材料。它面向学习者，使用中文说明知识点、代码行为、实验步骤和预期结果，可用于预习、复习和针对性提问。

这里的 `Day` 表示一个学习单元，不要求在一个自然日内完成。开始单元前先阅读对应的学习材料；完成实验后，再以材料中的检查问题复盘。

学习材料会提供少量与当前单元直接相关的中文或英文资料，并标明必读、选读和阅读重点。资料用于支持当前实验，不作为跳过动手过程的替代品。

当前总览见 [../week1_learning_plan.md](../week1_learning_plan.md)。
