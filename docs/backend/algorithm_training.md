# C++ 算法训练与错题机制

## 时间与数量

普通任务日 45 分钟，周六/周日各 60 分钟，约每周 5.75 小时。基准每周 3～4 道新题，另有旧题与限时练习；研究忙时减新题，保留复习。题目清单见 [12 周计划](roadmap_12_weeks.md)，题源见 [资料 B](foundations_and_resources.md)。

开始前用一道哈希题与一道双指针题诊断水平，不把已有能力当作零。新题可以替换为同知识点变体，但写入记录。

## 一次练习流程

1. 5 分钟：用自己的话写输入、输出、约束与边界。
2. 20～25 分钟：先写思路、复杂度，再独立用 C++ 实现与调试。
3. 卡住时按概念 → API → 结构 → 局部代码逐级请求提示；记录实际提示等级。
4. 剩余时间对照结果、记录错误、闭卷重写关键部分。首次使用题解当天不得记为“独立通过”。

困难题不要求 45 分钟解决；可拆成理解和闭卷复做两次。不要为题数连看多个答案。

## 复习规则

- 首次失败/依赖提示：加入 D+1、D+3、D+7、D+14 队列；这里的 D 是实际练习日期。
- 某次复做失败：记录原因，重新安排近期复做，不只沿用原到期日。
- 每周先做已到期的错题，复习占满时间时减少新题。
- 连续两次隔天闭卷通过、能解释复杂度与边界后，移到低频变体复习。
- 每周末 45 分钟限时练习，剩余 15 分钟复盘。开始采用 1 道中等或 2 道简单，后续按实际速度调整。
- 每月补一次 60～90 分钟混合模拟，从现有时间预算调剂，不额外透支。

## C++ 使用能力

围绕题目掌握 vector/string、unordered_map、queue/stack/priority_queue、sort/lower_bound、引用和 const、迭代器失效、整数溢出。每次记录时间/空间复杂度时考虑实际容器操作。

若投递 C++ 后台，另加 RAII、对象生命周期、编译链接、调试、并发与网络工程验收；算法通过不自动满足该门槛。
