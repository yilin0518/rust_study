### PJ-02 串行接口验收记录（2026-11-06）

证据来源：学习者在本次聊天提供的 PowerShell/curl 输出；助手没有代跑这些 HTTP 请求。

- 初始 GET /products：200，body 为 `[]`。
- 创建 Keyboard、Mouse：均为 201，ID 为 1、2；随后的列表包含对应商品。
- 纯空白名称、101 字符名称、price_cents=1000001、stock=1001：均为 400、空 body；每次失败后的列表仍只包含 ID 1、2。
- 再创建 Monitor：201，ID 为 3，说明上述失败请求未消耗 ID。
- GET /products/1、/2、/3：均为 200，返回内容与创建结果一致；GET /products/999：404、空 body。
- 业务校验：trim 后名称非空且最多 100 个 Unicode 标量值（chars().count()），价格不超过 1000000 分，库存不超过 1000；零价格/零库存边界尚未提供运行证据。
- next_id 使用 checked_add 检查后递增，均在同一把锁内；代码审查确认溢出分支在状态修改前返回 500，但尚无溢出运行证据。
- 尚未验收：并发创建、框架提取拒绝的实际响应、精确上限通过案例、统一错误 JSON、自动化测试；不据此宣称 V0 或整日任务已完成。
